# SEO MASTER PLAN — PORTFOLIO REBUILD

## Purpose

Updated SEO specification for the redesigned portfolio, including the newly differentiated Atlas NHD, ACE, and ERIS case studies.

The portfolio should target commercial intent around:

- full-stack development
- AI application development
- SaaS development
- RAG development
- business automation
- API and systems integration

## Canonical

Every indexable page should self-canonicalize.

Use one URL convention consistently, e.g. no trailing slash.

Do not canonicalize separate pages to the homepage.

Avoid duplicate query-string URLs.

## Robots

Recommended baseline:

```text
User-agent: *
Allow: /

Sitemap: https://YOUR-DOMAIN/sitemap.xml
```

Replace the placeholder with the real production domain.

Only disallow genuinely private routes.

## Open Graph

Each major page should have a custom OG title, description, URL, and image.

Case-study visual concepts:
- Atlas NHD → geospatial pipeline/map/report
- ACE → connected placement/CRM/document workflow
- ERIS → resource dashboard/state/audit trail
- ReadMindMe → retrieval/context/AI answer flow

Do not use one generic social image for every project.

## Performance and animation

The custom animations are part of the portfolio experience, but SEO and performance come first.

Use:
- lightweight animations
- transform/opacity where possible
- `prefers-reduced-motion`
- progressive enhancement
- server-rendered/indexable core copy where the framework supports it

Do not hide important SEO text behind animation.

## Final content rule

The portfolio must answer:

1. What do you build?
2. Who do you help?
3. How do your systems work?
4. Why should a client trust you?

Each case study must explain:

1. Business problem
2. What was built
3. Important design/engineering decisions
4. Technologies
5. Result or delivered capability

Do not promise Google position #1. Optimize for relevance, crawlability, useful content, internal linking, page experience, and conversion intent.
