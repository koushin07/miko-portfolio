# SEO MASTER PLAN --- Miko Cañares Portfolio

**Primary site:** https://ikoy.vercel.app/\
**Research date:** August 16, 2026\
**Purpose:** Production SEO specification for Claude Code.

> **Goal:** Build a technically strong, semantically coherent portfolio
> that can compete for high-intent searches around AI automation, n8n
> automation, RAG development, full-stack SaaS development, API
> integrations, and specialized geospatial software, while converting
> visitors into project inquiries.

> **Important:** No SEO plan can guarantee a #1 Google position. This
> plan maximizes relevance, crawlability, indexability, topical
> authority, first-hand evidence, and conversion intent without keyword
> stuffing.

# 20. CANONICAL STRATEGY

Every indexable page gets a self-referencing canonical.

Example:

``` html
<link rel="canonical" href="https://ikoy.vercel.app/projects" />
```

Rules:

-   HTTPS only
-   one canonical per page
-   preferred hostname only
-   no tracking parameters
-   no fragments
-   canonical must match sitemap URL
-   do not use robots.txt for canonicalization
-   do not canonicalize genuinely different pages to the homepage
-   use permanent redirects when retiring duplicate URLs

If a custom domain is introduced later:

1.  choose it as the canonical hostname
2.  301 redirect the Vercel domain
3.  update sitemap
4.  update canonical tags
5.  update Open Graph
6.  update JSON-LD
7.  update internal links
8.  resubmit the sitemap

-   use WebP/AVIF where appropriate
