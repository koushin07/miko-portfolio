### Case Study 1: Automated Lead Processing System

**Problem:**

The client had a manual workflow for processing raw uploaded data files, which was slow, repetitive, and error-prone.

**Solution:**

Built an automated workflow where the client/admin uploads a ZIP file to a Google Drive folder. The ZIP contains unsanitized `^` separated data. Once uploaded, an n8n workflow is triggered to:

- Capture the uploaded file
- Unzip and extract the data
- Sanitize and analyze the data
- Generate useful lead information
- Save leads to the database
- Make leads available through a React + WordPress customer-facing system

The customer-facing system used React embedded into WordPress and SurveyJS for structured intake and form handling.

**Tech involved:**

Google Drive, n8n, React, WordPress, SurveyJS, database storage, automation workflows.

**Result:**

Reduced manual processing, improved workflow reliability, and created a repeatable lead-generation system that clients/customers could access through a web interface.

---

### Case Study 2: ReadMindMe — AI/RAG Bible Study Platform

**Problem:**

Bible study and community platforms often lack personalized AI assistance, semantic search, cross-reference support, and contextual study tools.

**Solution:**

Built an in-progress full-stack AI-powered Bible study and Christian community platform using a modern backend architecture and AI/RAG pipeline.

**Features include:**

- AI-powered scripture Q&A
- Retrieval-Augmented Generation over scripture
- Vector search with PostgreSQL and pgvector
- Hybrid retrieval fallbacks
- Greek/Hebrew morphology enrichment
- Cross-references
- Multi-translation rendering
- User memory and personalization
- Streaming AI responses
- Background session summaries
- Prayer requests
- Devotionals
- Community features
- Admin console
- Moderation, audit logs, feature flags, rate limits, and security features

**Tech involved:**

Python, FastAPI, PostgreSQL 17, pgvector, Redis, OpenAI GPT-4o / GPT-4o-mini, OpenAI embeddings, SQLAlchemy async, Alembic, Pydantic, JWT, Google OAuth, TOTP, APScheduler, SlowAPI, Docker Compose, pytest.

**Result:**

Demonstrates hands-on AI/RAG, vector search, backend architecture, security-aware development, and production-shaped system design.
